WHY DIRECT

届けたい、
ということ。

安い野菜は、スーパーでも買えます。それでも、わざわざ畑の横まで足を運んで野菜を受け取ってくださる方がいらっしゃるのは、作った人の顔が見えるからだと思うのです。

育てた野菜のほとんどは、市場へ出荷されます。それでも、畑まで足を運んでくださる方には、その日に採れたものを直接お渡しすることがあります。流通の数字には載らない、小さなやりとり。だからこそ、その時間を丁寧にしたいと思っています。

旬の野菜のこと、保存方法、食べ方。気になることがあれば、畑で気軽に声をかけてください。短いやりとりの積み重ねが、お互いの安心感をつくっていくのだと思います。

「安い野菜は、スーパーでも買えます。

OUR VALUES

3 つの、こだわり。

大きな差別化ではなく、当たり前の積み重ねを大切にしています。 昨年と同じ味を、今年も。同じ畑から、来年も。

VALUE 01

旬を、その時季に

年中同じものを並べるのではなく、季節ごとに一番美味しい状態の野菜を収穫し、その週のうちにお届けします。早朝に収穫してその日のうちにお渡しするので、葉物のシャキッと感が違います。

VALUE 02

土から、ゆっくり

化学肥料に過度に頼らず、堆肥と緑肥を組み合わせた土づくりを大切にしています。土の力で育った野菜は、味が濃く、日持ちもよくなります。年に一度の土壌診断も行っています。

VALUE 03

家族で、丁寧に

大規模化はせず、家族で目が行き届く範囲で続けています。お客様の顔が見える距離感を、これからも大切にしたいと思っています。

STAPLES

畑の、主役。

毎年安定してお届けしている、萬代農園のメイン作物です。 これに加えて、年によって変わるプラスアルファの作物も育てています。

01
YEAR-ROUND / ハウス栽培
ほうれん草
ビニールハウスでの通年栽培。屋外が難しい盛夏や寒波の時期も、安定した品質でお届けできます。収穫量に余裕のあるときは、地域の子ども食堂さまへお分けすることもあります。
02
OPEN FIELD / 路地栽培
ジャガイモ
路地で育てる新じゃがを中心に。5 月から販売を始めます。過去には、大手スナック菓子メーカーさまへ出荷した実績もあります。
03
OPEN FIELD / 路地栽培
にんじん
冬の路地で栽培。寒さに当たることで甘味が強く引き立つのが特徴です。土の香りを残したまま、葉付きで販売することもあります。
EXPERIENCE

畑で、季節を、感じる。

ご家族で、お友達同士で、お一人でも。 畑で実際に手を動かしながら、季節を感じる時間をご用意しています。事前予約制です。

PROGRAM 01

季節野菜の収穫体験

90 分 / 通年 / 1 名から

その日の畑で旬を迎えている野菜を、ご自分の手で収穫。お持ち帰りはもちろん、その場でかじってみることもできます。子供さんの食育にも。

PROGRAM 02

春のじゃがいも掘り体験

半日 / 5月 – 6月 / 1家族

新じゃがの収穫時期にだけ実施する家族向けのプログラム。畑の土を掘り起こして、お子さまも一緒に楽しめます。終了後はジャガイモ 2kg をお持ち帰りいただけます。

PROGRAM 03

畑のキッチン / 季節の料理会

3 時間 / 季節ごと開催

収穫した野菜を、そのまま畑横のキッチンで調理してお召し上がりいただきます。地域の料理人さんを招くこともあります。要予約・定員 8 名まで。

PROGRAM 04

こどものための、野菜の絵

60 分 / 月 1 回 / 4〜10 歳向け

畑にある野菜を、紙とクレヨンでじっくり描いていただきます。「食べる前に、見る・触る・かぐ」を体験できる時間。野菜のお土産付き。
