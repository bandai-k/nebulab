# NEBULAB コーポレートサイト リニューアル 作業指示書

対象: nebulab.jp
作成日: 2026-09-03
関連: `nrt-loft-renewal-spec.md`（姉妹サイト NRT LOFT のリニューアル指示書）

---

## 0. 背景と目的

NRT LOFT を「AIでものづくりを発信するメディア」として切り出したことに伴い、
NEBULAB 側を**会社としての顔**に整理し直す。

あわせてデザインを刷新する。現行サイトは画像・写真が乏しく、
コピーとサービス説明だけで構成されているため、内容が抽象的で、
どの開発会社にも当てはまる見た目になっている。これを脱する。

### 読者の優先順位（今回の変更点）

1. **法人の開発案件を検討している人**（受託・SES・内製化支援）
2. **NRT LOFT から流れてくる「本格的に作りたい」人**
3. 成田の地域事業者（IT相談）

現行サイトは 3 が主導線になっている。**2と3を主役に、1は残すが主役から降ろす。**
地域事業者向けの入口は削除せず、優先度を下げる。

## 1. 進め方

Phase 1 だけは独立して先に実施し、単独でコミットする。
これは誤情報の削除であり、デザイン変更とは切り離す。

Phase 1 誤情報の削除 → 2 デザイン基盤 → 3 トップページ → 4 下層ページ → 5 メタ・仕上げ

各フェーズの終わりに `npm run build` が通ることを確認する。

```
成田・花崎町の一角を起点に、ゲストハウス・カフェ・アウトドアスペースを

```

## 4. Phase 2 — デザイン基盤

### 方向性

**ダークトーン + 成田の線画イラスト。**

深い紺色を基調とし、成田の風景（飛行機・管制塔・成田山新勝寺の五重塔・
新幹線・建物）を白の細線で描いたイラストを背景に薄く敷く。

このイラストがデザインの核。写真素材が乏しくても画面が空虚にならず、
かつ「成田の会社である」ことを説明文なしで伝える。
白線で描くことで挿絵ではなく**設計図面**の質感になり、
「設計する会社」という含みが出る。

線は塗りつぶさず、細く、背景に溶け込む薄さにする。
文字の可読性を損なわないこと。

### カラートークン

| 用途 | 値 |
|---|---|
| 背景 | `#0E1417` |
| 面（カード等） | `#161D21` |
| 罫線 | `#252E33` |
| 本文 | `#E4E7E6` |
| 補助テキスト | `#8A9499` |
| アクセント（真鍮） | `#C9A227` |
| 反転ブロック背景 | `#F7F6F1` |
| 反転ブロック本文 | `#2C2C2A` |

アクセントは主ボタンとごく一部のラベルのみ。**多用しない。**
これ以外の差し色は使わない。

### タイポグラフィ

- 日本語見出し: 細めの明朝、またはウェイトの軽いゴシック。字間を広めに
- 英字: グロテスク系サンセリフ。小さく、字間を広く
- 見出しを大きくしすぎない。文字の大きさではなく余白と線で構成する
- 数字（サービスの 01〜04）は細い明朝で大きめに。暗い面に浮かせる

### ライトテーマは実装しない

NRT LOFT がライト、NEBULAB がダーク。この対比が2つのブランドの
差別化そのものなので、切り替え機能は設けない。

### 動きについて

スクロールに応じた控えめな演出は可。ただし**全セクションに
機械的なフェードインを付けない**。動かすなら1〜2箇所に絞る。
`prefers-reduced-motion` を尊重すること。

## 5. Phase 3 — トップページ

上から順に以下の構成。

### 5.1 ヘッダー

左にロゴ「NEBULAB」、中央にナビ（ABOUT / SERVICES / PROJECTS / PARTNERS / CONTACT）、
右に問い合わせボタン。細く、背景に馴染ませる。

### 5.2 ヒーロー

左にコピーとボタン2つ、右に自社プロダクトの画面を映した端末
（ノートPC・タブレット・スマートフォン）を斜めに重ねて配置。
暗い背景の中で端末の画面だけが光って見えるようにする。
背景に成田の線画。

**コピーは実装時に詰める論点として残す。** 現時点の案:

```
つくるだけじゃない。
自ら使い、育てる会社です。
```

ただしこの案は「自ら使い」が誰にとっての価値か曖昧。
発注者にとっての価値は「自分たちで作って運用しているので、
運用まで分かっている」という点にある。その趣旨が伝わる案を
複数用意して提示すること。

### 5.3 自社プロダクト

カード4枚を横一列。各カードに画面キャプチャ、名前、1行の説明、技術タグ。

**4枚目に何を載せるかは既存サイトを調査して判断すること。**
候補は narita-guide.com / NAJIMI / SuperMindMap。
Nebula Place は構想段階のため除外する。
判断理由を添えて報告すること。

確定している3枚:
- Capture Box
- Navi
- みどりっこ

**注意:** デザイン案の画像には `BizRelay` という架空のプロダクトが
含まれているが、これは存在しない。使用しないこと。

### 5.4 サービス

4項目を横罫線で区切って縦に並べる。
左に細い番号 01〜04、中央に名前と説明、右に詳細リンク。アイコンは使わない。

```
01  受託開発      業務システムやWebサービスの設計・開発・運用までワンストップで
02  内製化支援    技術力向上や開発プロセスの整備を通じて、チームの自走をサポート
03  自社プロダクト 自ら課題を見つけ、プロダクトを開発・運用。得た知見を還元
04  地域のIT支援  成田市を中心に、中小企業や地域団体のIT活用・DXを支援
```

**04 は残すが、順序を下げることで優先度を表現する。** 削除しない。

### 5.5 代表メッセージ

左に代表の写真、右に短いメッセージ。背景に線画を薄く。

写真は暗めの室内で撮影したものを使う。
**明るい写真を暗い背景に置くと浮くため、撮影時に注意が必要。**
素材が用意できるまではプレースホルダを置く。

**代表者名は実際の表記を使うこと。** デザイン案の画像に含まれる
「星野 健太」「辻本 浩輝」はいずれも生成された架空の名前。
既存サイトの `/about` に正しい表記があるので、そこから取得する。

### 5.6 Partners

**3社ではなく2社。** デザイン案は3枠で組まれているが、2枠に変更する。
2社なので横幅に余裕がある。各社の説明を2行程度取り、
「単なる相互リンクではなく実際の協業関係が分かる」構成にする。

```
MMPR合同会社
（事業内容は要確認）

株式会社AIM
https://ai-management.biz/
代表取締役 石井一之
生成AI活用の企業研修。初級者向けに、ChatGPTなどの生成AIを
業務にどう活かすかを、企業の課題に合わせて設計した研修として提供。
```

AIM との関係は以下の三層構造として説明できると望ましい。

```
NRT LOFT   一般向けにAIものづくりを発信
   ↓
AIM        法人向けに生成AI活用研修
   ↓
NEBULAB    本格的なシステム・サービス開発
```

**注意:** デザイン案の画像に含まれる「ヒカリコンサルティング」
「ナリタデザイン」「クラウドプランツ」、および別案の
「cloudpack」「GOODLIFE」「SMARTCAMP」はすべて使用しないこと。
前者は架空、後者は無関係な実在企業。

### 5.7 NRT LOFT への導線

**このブロックのみ背景を `#F7F6F1` にして強い対比をつける。**
線画は逆に濃い線で描く。

```
SISTER MEDIA
NRT LOFT

欲しいものが無かったので、自分で作ることにした。

AIを使って「自分の困りごとを解決する小さな仕組み」をつくる過程を
発信しています。非エンジニア向けのメディアです。

[ NRT LOFT を見る ]
```

線画は**建物の外観**（成田・花崎町の旧釣具屋2階）。
デザイン案にあるコワーキングスペースの内装（長机とスツール）は使わない。

### 5.8 フッター

会社情報、ナビゲーション、連絡先。下部に成田の街並みの線画を横長に薄く。

**会社情報は既存サイトの実データを使うこと。**
デザイン案の画像に含まれる住所・電話番号・法人格
（「成田リシティビル 6F」「0476-85-7830」「NEBULAB Inc.」）はすべて架空。
実際は **Nebulab合同会社**（`LLC`。`Inc.` ではない）で、
所在地は NRT-LOFT 内。正確な情報は既存サイトの `/about` および
`/privacy` から取得する。

### `/services`

現行は3本立て（SES・受託開発 / 地域×テクノロジー / ECブランドNAJIMI）。
トップの4分類に合わせて再編する。

- 01 受託開発

**NRT-LOFT は「02 LOCAL × TECH」から外す。**

代表メッセージから Phase 1 の該当箇所を削除したうえで、
新しい事業構成に合わせて書き直す。
沿革の「2026.05 NRT-LOFTオープン」は事実なので残す。

### `/partners`（新規）

トップの Partners セクションの詳細版。2社。

## 7. Phase 5 — メタデータと仕上げ

- 全ページの title / description を新しい方向に合わせて書き直す

- NRT LOFT との相互リンクが両サイトで機能しているか確認

## 8. 品質基準

- モバイル対応必須
- **1024px 前後の中間幅で崩れないこと。**
  実装後、1440px / 1024px / 768px / 375px で表示を確認し、
  スクリーンショットで検証すること
- 見出しの折り返しは自動任せにせず、意図した位置で改行されるようにする
  （`word-break: keep-all` を適用）
- キーボードフォーカスが暗い背景でも視認できること
- ダーク背景でのコントラスト比を確認すること
- `prefers-reduced-motion` を尊重

## 10. 未確定事項（着手前に確認すること）

1. **代表の写真**が未用意。暗所での撮影が必要。プレースホルダで進めてよいか
2. **成田の線画イラスト**の制作方法。描き起こすか、生成するか
3. **MMPR合同会社の事業内容と掲載可否**。先方の許諾は取れているか
4. **AIM の掲載許諾**

6. ヒーローのコピー（5.2 参照）

ほぼすべて架空**である。レイアウトと配色のみを参考にし、
社名・人名・住所・電話番号・プロダクト名・パートナー企業名は
**必ず既存サイトまたはこの指示書の実データを使うこと。**

- 代表者名「星野 健太」「辻本 浩輝」
